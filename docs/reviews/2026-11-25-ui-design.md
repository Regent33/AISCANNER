# Design review: Paper Scanner teacher UI (2026-11-25)

Reviewers: `apple-design` (HIG foundations: web app, so platform conventions for macOS/iOS do not apply) and `design-taste-frontend` (scope note: dense product UI, so only its contrast, color-lock, radius-lock, states and copy rules apply).

## Summary
**Good.** Thesis: get a stack of scanned tests to "which topics do I reteach" with as few decisions as possible, while making the privacy promise visible (identity area drawn by the teacher, blacked out everywhere else). A deliberately quiet utility; its signature is the plain-language privacy copy plus redacted crops in Review.

## Critical (fixed)
- **Control boundaries at 1.25:1.** Inputs, selects, the textarea and secondary buttons used the `line` token (#e4e4e7 on #fdfdfd). WCAG 1.4.11 asks 3:1 for component boundaries (`accessibility.md › Strive to meet color contrast minimum standards`). Fix: new `control` token, #85858e light (3.59:1) and #73737d dark (3.81:1), on every interactive boundary. `line` stays for decorative card borders.

## Improvements
- **High (fixed): blank answers flooded Review at 0% confidence.** An empty box is the easiest thing to read, but OCR returned confidence 0. Now a clearly empty box reads as blank at 0.95; faint marks still go to a person at 0.3.
- **Medium (fixed): drawing the name/ID box was pointer-only.** The canvas is now focusable: Enter places a box, arrows move it, Shift+arrows resize, and the instructions are linked with `aria-describedby` (`accessibility.md`: keyboard use must work on desktop).
- **Medium (open): sidebar is fixed at 224 px.** Fine on a laptop, cramped under about 900 px wide. Add a collapse below `md` when tablet use is confirmed.
- **Low (open): raw server errors reach the UI** (for example "Not Found" before the report endpoint existed). Map common statuses to teacher-facing sentences in `HttpClient`.

## What works
- One accent (emerald) locked across both themes; one radius (0.5rem); semantic tokens switch with `prefers-color-scheme`.
- Labels sit above fields with hints below (`entering-data.md › Be clear about the data you need`). Every screen has empty, loading and error states. Empty states name the next action (`writing.md › Provide clear next steps on any blank screens`).
- Review is keyboard-first (Enter accepts, digits score, J/K move) with optimistic removal, so the next item appears without waiting for the network.
- No em-dashes, no decorative eyebrows, no icon-only controls without labels; icons come from one family (Phosphor, regular weight).
