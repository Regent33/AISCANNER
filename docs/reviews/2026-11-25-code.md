# Code review: layered UI + backend split (2026-11-25)

**Intent:** add the teacher UI in the owner's layered architecture and split the backend files that exceeded 250 lines, without changing behaviour.

**Verdict:** Approve after the fixes below (all applied in the same change).

## Critical
None.

## Major (fixed)
- `HttpClient.send` could throw on an empty or malformed JSON body (`await res.json()` sat outside the try), which broke its "never throws, returns Result" contract and would surface as an unhandled rejection. The body parse is now guarded.
- `POST /api/tests/{id}/key|syllabus` returned 500 on malformed JSON. It now returns 422; a regression test was added.

## Minor
- Fixed: unused `weakest` in `useReportViewModel`.
- Open: in the New test wizard, going Back to step 1 after the test was created and editing the name has no effect (the test already exists). Low impact; add a rename endpoint if teachers ask.
- Open: `useReviewKeys` re-binds the keydown listener on every render (handlers object changes). Correct but wasteful; switch to a ref if profiling shows it.
- Open: no frontend unit tests yet; flows are covered by the Playwright golden path (G10).

## Checked and clean
- Layering checked mechanically: no cross-feature imports; `shared/` never imports `app/` or `features/`; `domain/` imports nothing from React, TanStack or infrastructure; `data/` never imports `presentation/`.
- SQL: every f-string fragment is a constant (`NOW`, migration table/column names, settings field names from the Pydantic model). User values are always bound parameters.
- The backend split is behaviour-preserving: 43 pytest tests green, and the fixture output is byte-identical to the committed manifest.
- All files are within the 250-line limit (largest: frontend 73, backend 211).

## Praise
- One redaction choke point (`grade.redacted_page`) feeds both grading and the review crops, so privacy is structural.
- The optimistic review queue (`onMutate` removes the item, `onError` restores it, `onSettled` refetches) keeps the review flow fast without hiding failures.
